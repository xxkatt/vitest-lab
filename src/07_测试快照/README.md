# 07_测试快照

快照测试会保存一次运行的结果，后续运行时与它比较，帮助发现输出变化。首次生成或更新快照后，需要检查内容是否符合预期，并将快照与测试代码一起提交。

阅读 `snapshot.test.ts`，依次掌握 3 个例子，方法作用已写在调用处：

1. 使用 `toMatchSnapshot` 将对象保存为外部快照。
2. 使用 `toMatchInlineSnapshot` 将文本快照保存在测试代码中。
3. 使用 `expect.any(Date)` 匹配动态时间，其余字段仍与快照比较。

在项目根目录运行本章：

```sh
pnpm test --run src/07_测试快照
```

确认输出变化符合预期后，更新本章快照并检查差异：

```sh
pnpm test --run src/07_测试快照 -u
```
