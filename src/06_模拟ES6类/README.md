# 06_模拟ES6类

模拟 ES6 类可以替换真实的构造函数、实例方法和静态方法，让测试控制类的行为。

先看 `user.ts` 中的真实类，再阅读 `class.test.ts`，掌握 3 个例子，方法作用已写在调用处：

1. 使用 `vi.mock` 和 `vi.fn(class {...})` 替换类，验证构造函数的调用次数和参数。
2. 使用 `vi.mocked` 和 `mockReturnValue` 修改实例方法的返回值。
3. 调用模拟的静态方法，验证返回值和调用次数。

再看 `mailer.ts`、`register.ts` 和 `register.test.ts`：用注册后发送欢迎邮件的例子，模拟依赖的邮件客户端，验证创建客户端和发送邮件时的参数，无需启动后端或真实发送邮件。

在项目根目录运行本章：

```sh
pnpm test --run src/06_模拟ES6类
```
